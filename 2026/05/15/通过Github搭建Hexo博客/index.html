什么是 Hexo？

Hexo 是一个快速、简洁且高效的博客框架。 Hexo 使用 Markdown（或其他标记语言）解析文章，在几秒内，即可利用靓丽的主题生成静态网页。

什么是Qexo？

Qexo 是一个快速、强大、美观的在线 静态博客编辑器。使用 GPL3.0 开源协议。支持包括且不限于在 Vercel 等平台部署, 为您的静态博客添加动态的元素

优点

  • 静态博客，维护简单，没有服务器负载压力，尽管专心写手头文章
  • 0成本，天天摸鱼也没有后顾之忧🥰
  • 主题种类丰富，可配置选项多

缺点

  • 相比动态博客，交互性少一些，使用体验略低
  • 在线编辑文章需要独立后端，首次配置麻烦

本地初始化Hexo

安装Hexo

pnpm install hexo-cli -g

初始化Hexo

  1. 建立项目文件：mkdir hexo
  2. 项目文件初始化：cd hexo hexo init

介绍

比较重要的文件目录有

  • ./public用于存放生成的静态网页文件
  • ./source博客内容相关源文件，如 ./source/_post是博客文章markdown源文件
  • ./theme博客主题
  • ./_config.yml博客配置文件，类似的 ./_config.xxx.yml为主题配置文件
  • 剩余的为环境相关的文件，与博客内容无关

安装主题

安装Stellar主题，其他主题可自己查找，按Stellar文档配置好相关配置，当然后续也可进行更改

部署到Github

初始化配置

建立公共仓库

建立公共仓库存储博客静态文件username.github.io，此仓库可以可以直接访问实现前端部署，也可以自定义域名（此处不做说明）

建立私有仓库

  1. 建立私有仓库Hexo-Blog，存放博客源文件
  2. 把上面初始化的hexo文件同步到仓库，注意.gitignore，忽略不需要上传的文件

配置Action

添加Workflow文件

配置密钥

  1. 添加Github密钥Github -> Settings -> Personal Access tokens创建公共仓库Hexo的密钥
  2. 在私有仓库Hexo-Blog -> Settings -> Secrets and variables -> New repository secret，创建密钥Hexo -> Token
  3. 私有仓库和公共仓库都开启Workflow permissions的读写权限，Settings -> Actions -> General -> Workflow permissions -> Read and write permissions

然后试运行Action，没问题再开启Workflow的提交main分支自动运行

搭建Qexo

Qexo部署到Vercel，一键搭建，首次部署会报错，无视

配置Vercel PostgreSQL

点击 Storage -> Create Database -> Neon (PostgreSQL)，选择Washington, D.C., USA (East) - iad1位置的数据库，创建完毕后点击Connect Project 连接到你第一步创建的项目

点击Overview回到刚才创建的项目，Development -> Redeploy，等待配置完成若没有错误即可进入初始化引导

自定义Vercel域名

在上方创建的vercel项目中，点击 Settings-> Domains添加自定义域名，通过CNAME解析到vercel即可使用自定义域名访问

Qexo初始化配置

访问Qexo地址，进行初始化配置

Github密钥需要在Github -> Settings -> Personal Access tokens获取，没有保存也可按上方再申请一个，这里的Github仓库为存储hexo源文件的仓库Hexo-Blog，格式为 用户名/仓库名，项目分支 main

设置图床，Github，填写仓库、分支名、密钥、保存路径，保存路径填写包含目录+文件的完整路径
